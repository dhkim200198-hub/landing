# MOCA ROOM Landing Page

동네 카페 "MOCA ROOM"을 위한 심플한 원페이지 랜딩페이지입니다.

## 구성

- `index.html` — 페이지 구조 (Hero, 소개, 메뉴, 오시는 길, 문의)
- `style.css` — 전체 스타일링

## 실행 방법

별도 빌드 과정 없이 `index.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.

## 섹션

- **Hero** — 카페 슬로건과 메뉴 바로가기
- **About** — 카페 소개
- **Menu** — 대표 메뉴 및 가격
- **Location** — 주소 및 영업시간
- **Contact** — 연락처 및 SNS
